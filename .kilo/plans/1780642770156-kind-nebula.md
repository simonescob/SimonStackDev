# Redesign Plan for SimonStackDev

## Goal
Redesign the existing `index.html` portfolio site using Tailwind CSS via CDN to match the modern, dark-themed aesthetic from the provided reference code, while preserving all SEO metadata, structured data, analytics, and keeping all content on a single self-contained HTML page.

## Steps

### Step 1: Analyze Current State
- Current site: single `index.html` with inline styles and content
- Existing tech stack: pure HTML/CSS (no build tools, no external CSS/JS files)
- Assets in use: `/og.png`, `/favicon.svg`, Hotjar, Simple Analytics, Google verification meta, JSON-LD structured data (FAQPage, Person, Service x4, BreadcrumbList)

### Step 2: Identify Target Design Requirements
Based on the screenshot and provided reference code:
- **Dark background** (`#0C0C0C`)
- **Cyan/teal accent color** (`#5BBECB`)
- **Sticky navigation** with "Simón Escobar" logo, links (About, Skills, Projects, FAQ), and "Hire Me" button
- **Hero section**: large headline, tagline, two CTA buttons, profile image with glow effect
- **Stats strip**: 5+ Years, 30+ Projects, 100% Satisfaction, ∞ Lines of TypeScript
- **Technical Skills**: pill/badge style tags, "Curated Technology Stack" label
- **About Me**: two-column layout (heading + divider | bio text)
- **What I Build**: 3-card grid with Material Symbols icons
- **Featured Projects**: project cards with image areas, tech tags, "See all experiments →" link
- **FAQ**: accordion/dropdown with 4 questions
- **CTA section**: cyan/teal background, heading, subtext, "Let's Connect" button
- **Footer**: dark minimal footer with Simón Escobar name and social links

### Step 3: SEO / AEO Safeguards
- Preserve all head elements exactly: Hotjar, Google verification, canonical, Open Graph, Twitter Card, theme-color, preconnect/preload, favicon, sitemap, hreflang
- Preserve all JSON-LD structured data verbatim: `Person`, `WebSite`, `WebPage`, `FAQPage` (6 questions), `Service` x4, `BreadcrumbList`
- Ensure FAQ accordion content matches JSON-LD `acceptedAnswer.text` values exactly
- Preserve Simple Analytics with privacy-first config and noscript fallback
- Do not introduce any external script libraries except the Tailwind CDN

### Step 4: Adopt Tailwind CSS via CDN
- Use `https://cdn.tailwindcss.com?plugins=forms,container-queries` CDN as styling foundation
- Use provided Tailwind config extending colors, spacing, font sizes, font families, and border radius
- Use Google Fonts: Sora (headings/display), Inter (body), JetBrains Mono (labels/code)
- Use Material Symbols Outlined for icons
- Maintain single-file HTML with inline `<script>` Tailwind config and custom CSS

### Step 5: Implementation Plan (in `index.html`)
1. **Preserve head content exactly**: merge from current `index.html` verbatim (all meta, OG, JSON-LD, analytics)
   - Remove duplicated font links; use optimized single Google Fonts link + Material Symbols
   - Keep Tailwind config script in `<head>`
2. **Replace inline CSS with Tailwind + minimal custom CSS**:
   - Use provided `glass-panel`, `hero-glow`, `custom-scrollbar` utility classes
   - Implement all layout via Tailwind utility classes
3. **Update HTML structure** using provided reference code, but with current site's text/content:
   - Nav: sticky, logo, links, Hire Me button
   - Hero: two-column grid, headline, tagline, CTAs, image with glow
   - Stats: grid with 4 stats
   - Skills: header with "Curated Technology Stack" + pill tags
   - About Me: two-column layout with heading + divider
   - What I Build: 3 glass-panel cards with icons
   - Featured Projects: project cards with image areas, descriptions, tech tags, "See all experiments" link
   - FAQ: accordion with onclick toggle + Material Symbols expand icon
   - CTA: teal background section
   - Footer: name + social links
4. **Preserve functional JS**:
   - Smooth scroll for anchor links
   - FAQ accordion toggle
   - Intersection observer fade-in animations
5. **Update footer content** to match current site (© 2026 Simón Escobar, GitHub, LinkedIn, Twitter, Email)

### Step 6: Files to Modify
- `index.html` — complete rewrite of body structure and styles while preserving head metadata and JSON-LD exactly
