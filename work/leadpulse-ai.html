Case Study

LeadPulse AI

An AI-powered lead scoring and CRM enrichment platform that automatically surfaces high-intent prospects and reduces sales cycle time.

RoleLead Full-Stack Developer
StackNext.js · Node.js · OpenAI · PostgreSQL
Year2025

Overview

LeadPulse AI is a B2B SaaS platform designed for sales teams at high-growth startups. The core problem it solves: sales reps waste hours manually researching leads and deciding which ones to prioritize. LeadPulse automates this by ingesting leads from multiple sources — web forms, CSV imports, CRM integrations — and running each through an AI scoring pipeline that assigns a quality score, enriches missing contact data, and flags high-intent signals.

I designed and built the full product from architecture through to production deployment on Vercel, including the API layer, the AI pipeline, the real-time dashboard, and the Stripe-based billing system.

Technical Stack

Next.js 14 TypeScript Node.js OpenAI API PostgreSQL Supabase Tailwind CSS Stripe Vercel Zod

The Problem

Sales teams at early-stage B2B companies receive dozens to hundreds of inbound leads per week. Without proper tooling, reps spend 30–40% of their time on manual lead research — checking LinkedIn profiles, verifying company sizes, and trying to gauge purchase intent from limited data. Low-quality leads eat into quota, and hot leads fall through the cracks because the team can't act on them fast enough.

Existing CRM tools provide storage and workflows, but none offered an intelligent layer that could automatically score a lead the moment it arrived and tell a rep exactly why it was — or wasn't — worth pursuing.

Architecture & Implementation

The platform is built as a full-stack Next.js application using the App Router. Server Actions handle lead ingestion and mutation operations, while API Routes power the webhook receivers for third-party CRM integrations (HubSpot, Salesforce). A dedicated Node.js worker process manages the AI scoring queue, ensuring that the main web application stays fast even when processing large lead batches.

The AI scoring engine sends structured lead data to the OpenAI API with a carefully tuned system prompt that evaluates company fit, role seniority, industry, and behavioral signals. Responses are validated with Zod before being persisted to PostgreSQL via Supabase. Each score is accompanied by a human-readable explanation, giving reps full transparency into why a lead ranked highly — this was critical for sales team adoption.

Data is stored in PostgreSQL with a multi-tenant schema: each customer organization has isolated lead tables, with row-level security enforced at the database layer via Supabase RLS policies. Authentication uses Supabase Auth with Google OAuth and magic link options.

Key Features Delivered

The product shipped with a real-time lead dashboard showing live scoring updates via Supabase Realtime subscriptions — reps can watch a new lead move from "processing" to "scored" in the UI without refreshing. The dashboard supports custom filter views, bulk actions (archive, assign, export), and a Kanban-style pipeline view.

A REST API with API key authentication lets customers push leads programmatically from their own systems without going through the UI. Rate limiting is enforced at the edge via Vercel middleware. Usage analytics are tracked per API key for billing purposes.

The Stripe integration handles subscription billing with multiple tiers (Starter, Growth, Enterprise), usage-based overage charges for lead volume, and a self-serve upgrade/downgrade flow — no manual intervention required from the operator side.
