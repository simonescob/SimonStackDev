Case Study

PitchLens

An AI pitch deck analyzer that gives founders instant, investor-grade feedback on their fundraising decks — before they ever step into an investor meeting.

RoleFull-Stack Developer
StackNext.js · OpenAI · PDF Parsing
Year2025

Overview

PitchLens is a web application that lets startup founders upload their pitch deck and receive a detailed, structured analysis within seconds. Instead of paying a consultant or waiting weeks for investor feedback, founders get an objective breakdown of their narrative clarity, market sizing, traction story, business model, and slide design — along with concrete, prioritized suggestions for improvement.

I built PitchLens end to end: the deck upload and parsing pipeline, the AI analysis engine, the report rendering UI, and the serverless deployment on Vercel.

Technical Stack

Next.js 14 TypeScript OpenAI API pdf-parse Vercel Blob Tailwind CSS Serverless Functions Zod

The Problem

First-time founders rarely get honest, structured feedback on their pitch decks until they're already in front of investors — at which point a weak deck can cost them the round. Professional deck review services are expensive and slow, and asking friends or advisors yields inconsistent, subjective opinions. There was a clear gap for an affordable, instant tool that applies a consistent investor lens to any deck.

Architecture & Implementation

PitchLens is built on Next.js with the App Router, deployed entirely on Vercel's serverless platform. When a founder uploads a deck, the PDF is stored in Vercel Blob and the text content of each slide is extracted server-side using a PDF parsing library. Because pitch decks are visual documents, the extraction step also captures slide structure and ordering so the AI can reason about narrative flow, not just raw text.

The extracted content is sent to the OpenAI API with a multi-section system prompt modeled on how real investors evaluate decks: problem clarity, market opportunity, solution differentiation, traction and metrics, team, business model, and ask. The model returns a structured JSON response — validated with Zod — containing a score and specific feedback for each dimension, plus an overall summary and a prioritized list of fixes.

Long-running analysis is handled within Vercel serverless functions with streaming responses, so founders see the report build section by section rather than staring at a spinner. The report UI renders each dimension as an expandable card with its score, strengths, weaknesses, and actionable recommendations.

Key Features Delivered

The core flow is deliberately frictionless: drag-and-drop a PDF, wait a few seconds, get a full report — no account required for the first analysis. Founders can then create an account to save reports, track revisions over time, and compare how their deck improved between versions.

Each analysis produces a shareable report link, letting founders send the breakdown to co-founders or advisors. The design feedback dimension uses the parsed slide layout to flag common issues like text-heavy slides, missing key metrics, and inconsistent visual hierarchy.
